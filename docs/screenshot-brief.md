# 插件截图任务书（交给另一个 agent 执行）

> 目标：为四个 Obsidian 插件产出**可上架用的截图素材**。
> 这些图有两个去处，规格不同，都要出：
> - **A. 目录详情页的截图栏**（官方要求：桌面 **1200×800**，最多 5 张，JPEG/PNG/WebP，单张 ≤5MB）
> - **B. 仓库 README 内的插图**（用于 GitHub 与目录 Overview 的 README 渲染，建议宽 1200px）

---

## ⚠️ 执行前必读：隐私

**绝对不要用真实 vault 截图。**

真实 Notes 的文件夹名、笔记标题、正文都会**永久公开**在插件市场页面上，
且会被搜索引擎与爬虫收录（`community.obsidian.md` 是公开站点）。

**必须**新建一个**演示 vault**，例如 `<盘符>:\obsidian-plugin-demo\`，其中：

- 文件夹名用中性英文或中文通用词：`Projects/` `Archive/` `Reading/` `Inbox/` `Daily/`
- 笔记内容是**占位文本**（`Lorem ipsum` 或复述的示例段落），不要出现真实人名、学校、公司、邮箱、电话
- 不要出现个人头像、真实聊天记录、私人待办
- 截图前**检查一遍窗口标题栏与侧边栏**，确认没有暴露 vault 路径或其他 vault 名

演示 vault 只需装**被截图的插件本身**（及其依赖），不要装其他个人插件 ——
它们的界面/图标会一起入镜。

---

## 通用规格

| 项 | 要求 |
|---|---|
| 窗口尺寸 | 固定录制/截图窗口，使**成品为 1200×800**（16:9 桌面）。建议窗口设为 1200×800 后整窗截图；若含系统边框，截完后裁到正好 1200×800 |
| 主题 | 先出**深色**一份（插件市场默认深色，视觉更整齐）；有余力再出浅色一份 |
| 字体 | 默认字体即可，不要用自定义字体 —— 否则和用户实际观感不一致 |
| 缩放 | Obsidian 缩放保持 100%，不要为了"显得满"而放大 |
| 格式 | PNG（无损，图标/细线更锐）；若单张超 3MB 再转 WebP |
| 单张大小 | ≤ 5MB |
| 命名 | `<plugin-id>-<场景>.png`，全小写连字符。例：`quiet-shelf-hidden-tree.png` |
| 输出位置 | 先全部放一个临时目录，由人工挑完后归档 |

**每个插件出 3–5 张：1 张主界面 + 2–3 张功能特写。**
特写可以裁剪放大，但**不要切得看不出上下文** —— 至少要留出能辨认的 UI 边框。

## 1. `quiet-shelf`（暗格）—— 上架中，优先补

演示 vault 准备：造 8–12 个文件夹、每层放几个 `.md`，其中 2–3 个文件夹命名为
`Archive/`、`Reading/`、`Inbox/`，另放几个 `readme.md`、`inbox.md`。

| # | 场景 | 画面要求 |
|---|---|---|
| 1 | **主界面：文件树收起效果** | 左侧文件树，`Archive/`、`Reading/` 已被「暗格」收起（列表里看不到），其余正常显示。鼠标不要悬停在任何项上 |
| 2 | **暗格管理面板** | 打开暗格面板，能看清"已收起 / 未收起"两组与勾选项 |
| 3 | **聚焦模式** | 只选中两个文件夹后的文件树：仅该组及其祖先/后代可见，其余消失。**同一张图里最好能对比出"收起前/后"**，可考虑左右拼图 |
| 4 | （可选）**设置页** | 插件设置界面，展示开关项 |

### 动图怎么录（比逐帧截图靠谱）

用 **ScreenToGif**（Windows 免费）或同类工具，录制区域固定为 1200×800：

1. 开始录制
2. 按 `Alt+Z` 起一个计数 → 连按 `Space` 五次（正好写完一个「正」）
3. 继续按到第二组的第一笔
4. 按 `Enter` 提交
5. 停止录制

导出要求：**GIF，宽度 1200px，帧率 12–15fps，控制在 3MB 以内**（必要时裁掉无关区域）。
不要导出超过 5MB 的 GIF —— 目录页加载会很慢，反而扣分。

5. 生成上传到目录后台「Edit listing → screenshots」的那 5 张
6. 若是多帧素材，合成 GIF

## 附：常见错误（请避免）

- ❌ 用真实 vault → 笔记名/正文永久公开
- ❌ 窗口不固定尺寸，成品每张大小不一 → 详情页上排版会乱
- ❌ 截进个人主题/字体/其他插件 → 和用户实际观感不符，也像"私人配置展示"
- ❌ 图里有鼠标指针、系统通知弹窗、时间戳
- ❌ 为了好看把 Obsidian 缩放调到 150% → 字大到不真实
- ❌ GIF 超过 5MB
